# 阿里云上手指南（BladeDefect Round 2 专用）

> 给谁看：接手 Round 2 实验、但没怎么用过阿里云的人。
> 目标：从"登录控制台"一路走到"两臂开跑"，中间不用猜。
> 配套文档：`docs/v3_round2_handover.md`（要做什么）；机型与参数见负责人提供的《阿里云 GPU 抢占实例租用与训练操作说明》（外部文档，未入仓）。
> 本文只讲**怎么点**，不讲为什么做这个实验。

---

## 0. 先花两分钟建立心智模型

阿里云就是**租电脑**。搞懂 7 个词，后面全通：

| 词 | 大白话 | 本项目里它是啥 |
|---|---|---|
| **地域 / 可用区** | 机房位置。"华东1（杭州）"是地域，"杭州 I 区"是里面的一栋楼 | 全程只用 **杭州**，楼固定 **I 区** |
| **实例 (ECS)** | 一台租来的电脑 | 装 2 张 V100 或 1 张 A10 的机器 |
| **镜像** | 装机的系统盘 | Ubuntu 22.04（**不是 Windows**） |
| **云盘** | 硬盘。可以随电脑释放，也可以单独留着 | 500G 数据盘，**里面装着 193G 数据和成果** |
| **快照** | 给硬盘拍的照片，能从照片再变出一块新硬盘 | 前任留给你的那块 500G 盘的"照片" |
| **安全组** | 防火墙 | 只开 22 端口（SSH），别人进不来 |
| **公网 IP** | 门牌号 | 你从自己电脑 `ssh` 连它 |

**一句话记住整个流程：**

> 接快照 → 用快照变出一块硬盘 → 租一台带 GPU 的电脑 → 把硬盘插上 → 从自己电脑连进去 → 装环境 → 跑。

## 3. 第 1 步：接受共享快照（只有你能做）

1. 打开 <https://resourcemanager.console.aliyun.com/resource-shares>
2. 左边选 **资源共享 → 共享给我**
3. 顶部地域切到 **华东1（杭州）**
4. 找到那条记录，**状态**列点 **接受** → 确定

接受后，去 ECS 控制台 → 快照 → 点 **云盘快照** 标签页，应该能看到一行：

- "快照来源" = **共享来的快照**
- 鼠标悬停前边的小图标，会显示 `acs:ecs:sharedFrom:<对方UID>:<地域>:<快照ID>`

> 看不到？那不是你的问题，让对方按下面 4 条自查：
> ① 共享的账号 ID 是不是你右上角头像里的**主账号 UID**；
> ② 路径是 `ECS → 快照 → 云盘快照 → 操作列 ⋯ → 共享快照`；
> ③ 资源使用者范围必须选"**允许共享给任意账号**"；
> ④ 地域必须是杭州，中国站账号不能共享给国际站。

## 4. 第 2 步：用快照创建 500G 云盘

⚠️ **先想清楚可用区**：盘和实例**必须在同一个可用区**（杭州 I 区），否则挂不上去。

1. ECS 控制台 → 存储与快照 → **块存储 → 云盘** → **创建云盘**
2. 关键几项：

| 项目 | 选什么 |
|---|---|
| 地域 | 华东1（杭州） |
| 可用区 | **杭州 I 区**（不要随机） |
| 创建方式 | **从快照创建** → 选"共享来的快照" |
| 云盘类型 | **ESSD** |
| 性能级别 | PL0（够用，最便宜） |
| 容量 | snapshot 默认 500 GiB，**不要改小** |

3. 确认。创建需要一段时间（193G 数据，从快照恢复盘通常几分钟到几十分钟）。

> **不要**在这一步做"新建空白盘"，那样你拿到的是空盘，数据还在快照里，白花一份钱。

## 5. 第 3 步：创建抢占式 GPU 实例

路径：ECS 控制台 → **实例** → **创建实例** → **自定义购买**（不是"快速购买"，也不是"免费试用"）。

逐项对照（**照抄这张表，不要凭感觉**）：

| 购买页项目 | 选什么 | 备注 |
|---|---|---|
| 付费类型 | **抢占式实例** | 不要包年包月 |
| 地域 | 华东1（杭州） | |
| 可用区 | **杭州 I 区**（固定选） | 必须和第 2 步的盘同一个楼 |
| 实例规格 | 单卡：`ecs.gn7i-c8g1.2xlarge`（A10 24G）<br>双卡：`ecs.gn6v-c8g1.4xlarge`（2×V100） | **选哪个问负责人**，详见 §10 |
| 镜像 | **Ubuntu 22.04 LTS** | 不要 Windows、不要 Alibaba Cloud Linux |
| GPU 驱动 | 若页面有"**自动安装 GPU 驱动**"，**勾上** | 不勾开机后 `nvidia-smi` 会报错 |
| 系统盘 | ESSD **PL0，80 GiB** | 默认 40G 太小 |
| 数据盘 | **数量 0** | 盘在第 2 步已经有了，别重复买 |
| 公网 IP | 勾选**分配公网 IPv4** | 按流量计费即可 |
| 带宽 | 5 Mbps 或按使用流量 | SSH 够用 |
| 安全组 | 新建一个，只放行 **TCP 22**，来源填**你自己的公网 IP** | 别开 0.0.0.0/0 |
| 登录凭证 | **密钥对** → 新建 → 自动下载 `.pem` | 文件丢了就进不去，存好 |
| 实例名称 | 例如 `bladedefect-r2` | 方便对账 |
| Spot 使用时长 | 设定 **1 小时** | 前 1 小时有保护 |
| 出价方式 | **自动出价** | |
| 中断模式 | **节省停机** | 被抢占时盘还在 |
| 自动释放时间 | 暂时**不设** | 实验没跑完别自动删 |

点"确认订单 → 创建"。大约 1–2 分钟开机。

## 6. 第 4 步：挂盘到 /data

### 6.1 在控制台挂载

ECS 控制台 → 块存储 → 云盘 → 找到你那块 500G 盘 → **挂载** → 选刚建的实例 → 确定。

### 6.2 在服务器里挂载

```bash
# 1) 看到盘（应该是 /dev/vdb 或 /dev/vdc，以下统称 vdb）
lsblk

# 2) 建挂载点
sudo mkdir -p /data

# 3) 挂上去
sudo mount /dev/vdb /data

# 4) 确认里面有东西
ls /data
df -h /data
```

**🚨 绝对不要执行 `mkfs.ext4`。** 这块盘里有数据，格式化等于把 193G 全删了。
只有一块全新的空盘才需要 mkfs，你这块不是。

### 6.3 写进 fstab（开机自动挂载，防呆）

```bash
sudo blkid /dev/vdb          # 记下 UUID="xxxx-xxxx"
sudo cp /etc/fstab /etc/fstab.bak
echo 'UUID=你刚看到的UUID  /data  ext4  defaults,nofail  0  0' | sudo tee -a /etc/fstab
sudo mount -a                # 没报错就成功
```

`nofail` 很重要：万一盘没挂上，也不至于开不了机。

## 7. 第 5 步：SSH 登录

Windows 自带 OpenSSH，直接在 PowerShell 里：

```powershell
ssh -i C:\Users\你的用户名\Downloads\xxx.pem root@公网IP
```

第一次会问 `yes/no`，输入 `yes` 回车。

**常见报错：**

| 报错 | 原因 / 解法 |
|---|---|
| `UNPROTECTED PRIVATE KEY FILE` | `.pem` 权限太宽。右键文件 → 属性 → 安全 → 高级 → 只保留你自己 → 确定 |
| `Connection timed out` | 安全组没放行 22，或来源 IP 不是你现在的 IP |
| `Permission denied (publickey)` | 用错密钥，或实例没绑定这个密钥对（重建实例时常见） |

进去先看三样：

```bash
nvidia-smi        # GPU 认得到吗
df -h /data       # 数据盘挂上了吗
free -g           # 内存
```

## 9. 第 7 步：开跑

```bash
cd /root/BladeDefect          # 或你 clone 的目录
git checkout <负责人确认的分支>
tmux new -s a0                # 起个会话，断网也不掉
```

在 tmux 里跑训练命令（具体命令按交接文档 / 配置文件，不要手改参数）。

**tmux 三个必须会的操作：**

| 操作 | 按键 |
|---|---|
| 离开但让它继续跑 | `Ctrl+B` 然后 `D` |
| 回来 | `tmux attach -t a0` |
| 看有几个会话 | `tmux ls` |

跑起来之后，**每半天看一次**：

```bash
nvidia-smi
tail -5 runs/<实验名>/results.csv
```

## 11. 钱：怎么算、怎么不烧

### 计费规则

- **只有"运行中"才收计算费**（vCPU+内存+GPU）。
- **停机也收费**：云盘、公网 IP 继续按小时算钱。
- 云盘 500G ESSD PL0 ≈ ¥0.5/小时 ≈ **¥12/天**，这是你忘记关机时的主要损失。

### 设一个预算提醒（强烈建议，5 分钟）

费用与成本 → 预算管理 → 新建预算 → 金额填 **400** → 提醒阈值 80% → 通知到你手机/邮箱。

### 每天结束前查 4 项

```
1. 实例还在跑吗？还有任务吗？没任务就停机
2. 今天花了多少？（右上角"费用"）
3. /data 挂载还在吗？（df -h /data）
4. 成果写进 /data 了吗？（别只留在系统盘）
```

### 省钱三档

| 状态 | 怎么操作 | 成本 |
|---|---|---|
| 正在训练 | 正常运行 | 按小时计费 |
| 今天不跑了 | 实例 → **停止**（节省停机） | 只剩云盘 ~¥12/天 |
| 这轮做完了 | 先做快照 → **释放实例**（不勾云盘）→ 快照完成后释放云盘 | 快照 ~¥25/月 |

> 释放实例时**千万不要**勾"同时释放云盘"，除非你已经确认成果都进了快照。

## 12. 十个最容易踩的坑

1. **进了"免费试用"页** → 那里没有 GPU，退出重进"自定义购买"。
2. **找不到"共享快照"标签页** → 根本没这个标签，去"资源共享控制台 → 共享给我"接受邀请，再回"云盘快照"看。
3. **快照列表空、显示 0 个** → 上一行没接受邀请，或者对方共享到了错账号。
4. **盘建好了挂不上** → 盘和实例不在同一个可用区。
5. **`mkfs` 了有数据的盘** → 数据全没。永远先 `lsblk` + `blkid` 看清楚。
6. **`nvidia-smi` 报错** → 镜像没勾"自动安装 GPU 驱动"。
7. **SSH 连不上** → 安全组 22 没放行 / 来源 IP 变了。
8. **`.pem` 权限报错** → Windows 上改文件安全属性，只留自己。
9. **训练跑到一半没了** → 没用 tmux，SSH 一断进程就死。
10. **关机了还在扣钱** → 停机只免计算费，云盘和 IP 照收。
