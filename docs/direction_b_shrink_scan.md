## 三、为什么收缩不管用（机制解释）

1. **收缩同时伤害已 ok 的实例**：s=0.90 时 ok 从 585 掉到 497（−88），因为 ok 组本来 IoU 就高（中位数 0.81），收缩把一部分推到 0.75 以下 → 变成 mislocalized。
2. **净转化始终为负或个位数**：mislocalized 组（IoU 0.5–0.75）的边界误差不是"整体偏大"造成的，收缩不能定向修正。
3. 这与你的方向 B 报告结论一致：预测**系统性偏大**（面积比 p50 1.33–1.39），但偏大不必然导致 IoU 不足——真值本身形状不规则，缩小反而丢覆盖。
4. s=0.95 的 mAP 微升（+0.0038）主要来自 precision 侧的 FP 减少，不是 recall 侧的转化；属于"用检出换分数"，代价是漏检增多（5,227→5,178 反而少了…注意这里 missed 也降了 49，说明有少量 missed→mislocalized/ok 的转化）。
