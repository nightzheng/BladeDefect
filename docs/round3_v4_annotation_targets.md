## 四、定位层产物（怎么用）

### 4.1 `v4_补标_贫桶汇总.csv`（131 行）

| 列 | 说明 |
|---|---|
| class_id / 类 | 类别 |
| area_bucket / aspect_bucket | 形态桶（面积 6 档 × 长宽比 5 档） |
| n_train / n_val | 桶内实例数 |
| val_miss / val_miss率 | 桶内 val 漏检数与比率 |
| **缺口_补到10** | max(0, 10 − n_train)，即该桶还需补几个标注 |
| 优先级 | P0（五类）/ P1 |
| train候选图数 / val候选图数 | 该桶实例分布在多少张图里 |

### 4.2 `v4_补标_候选图.csv`（逐实例，贫桶内全部）

| 列 | 说明 |
|---|---|
| 优先级 | P0 / P1 |
| class_id / 类 / area_bucket / aspect_bucket | 定位桶 |
| split | train / val |
| 图片 / gt_index | 候选图与实例行号 |
| 面积px2 / 长宽比 | 实际形态参数 |
| val类别 | val 实例的匹配结果（missed / ok / mislocalized / misclassified；train 为空） |

**用法**：
1. 按 `优先级=P0` 且 `缺口_补到10 > 0` 的桶筛选
2. 从该桶的 `train` 候选图里挑**与现有样本拍摄条件不同**的图（避免同批次连拍）
3. val 侧候选图（362 张）可作为**验收对照**：补标后这些实例应能被检出
