## 核心结论

1. OBB 在 Box 指标上全面优于 seg（mAP50 +0.069），旋转框对倾斜缺陷定位更准，但 OBB 由 polygon 自动派生，不等同人工旋转框真值，暂不替代 15类 seg 主线。
2. 6类 mAP50 略高于 15类（+0.012），但训练预算不同（50 vs 100 epochs），保持 15类主线、6类辅助。
3. 同图成对置信度：6类更高 2611 张、15类更高 945 张、相等 3688 张（共 7244 张 val）。
4. 漏检仍是主要瓶颈，困难类别 13/8/14 召回最低。
5. 15类聚合到6类属于诊断分析，独立6类重训练属于模型实验，两者不互相替代。
