## 核心结论

1. OBB 在 Box 指标上全面优于 seg（mAP50 +0.069），旋转框对倾斜缺陷定位更准。
2. 6类 mAP50 略高于 15类（+0.012），但训练预算不同，保持 15类主线、6类辅助。
3. 同图成对置信度：6类更高 2611 张、15类更高 945 张、相等 3688 张。
4. 漏检仍是主要瓶颈，困难类别 13/8/14 召回最低。
5. 15类聚合与独立6类重训练分属诊断分析/模型实验，不混算。
